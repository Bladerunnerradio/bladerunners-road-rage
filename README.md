# Bladerunner’s Road Rage V14: Radio Station Landmarks Edition

Extract the entire ZIP. Open `index.html` in Chrome, Edge or Firefox. Keep the MP3 and both PNG images alongside index.html.

New in V14:
- KATT replaces Evel Knievel Memorial Hospital.
- Radio station buildings Z-ROCK, KSDZ, KXLV, XM RADIO, MYROCK 96.5 and 99X occupy formerly generic building slots.
- Silver triangular 96 ROCK WKLS building with distinctive roof.
- Original orange/yellow Bladerunner Radio logo in roundabout center.
- Original skull Bladerunner Radio logo on Golden Microphone winner celebration screen.

All V13 gameplay, controls, grass slowdown, collision sayings, automatic high scores, roadblocks, wraparound roads, fireworks, and included soundtrack are retained.

Scores remain saved in each browser's local storage.

This edition highlights the current completed game's entry in RED on the results leaderboard if it ranks in the top ten. Earlier records remain intact.
